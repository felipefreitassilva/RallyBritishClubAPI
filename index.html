Modelo

Modelos de dados do Rally

Esta página reúne os arquivos usados pelo aplicativo dos juízes e pelo site de apuração de resultados do Rally British Club. A cada edição do rally, esses arquivos são atualizados com os dados reais daquele ano: carros inscritos, juízes de cada posto e horários de largada. O que você vê abaixo são os arquivos-modelo — o ponto de partida que a organização de cada ano deve preencher com os dados do seu evento.

Arquivos-modelo

Carros carros.csv

Lista de carros inscritos. Preenchido manualmente pela organização, ano a ano.

Numero,Motorista,Navegador,Modelo,Cor
1,Piloto Exemplo,Navegador Exemplo,Modelo Exemplo,Cor Exemplo
Preenchido pela organização

Detalhes dos carros carDetailOptions.json

Controla quais colunas o app dos juízes mostra sobre cada carro (id, modelo, tripulação, tempo decorrido).

{
  "showId": false,
  "showModel": false,
  "showPeople": false,
  "showTimePassed": true
}
Ajustado pela organização

Hora de saída — Ida horaSaidaIda.txt

Horário oficial de largada do primeiro carro no trecho de ida, no formato do exemplo abaixo.

2000-01-01T08:00:00.000Z
Preenchido pela organização

Hora de saída — Volta horaSaidaVolta.txt

Mesmo formato do arquivo de ida, para o horário de largada do trecho de volta.

2000-01-01T14:00:00.000Z
Preenchido pela organização

Juízes — Ida juizesIda.csv

Um posto por juiz (ou dois juízes no mesmo posto, separados por &). A coluna Tempo Posto não é digitada à mão — é gerada pelo site de apuração ao cifrar o horário real do posto. 

Posto,Nome,Tempo Posto
1,Juiz Exemplo,000000000000
Gerado pelo site de apuração

Juízes — Volta juizesVolta.csv

Mesmo formato do arquivo de ida, para os juízes do trecho de volta.

Posto,Nome,Tempo Posto
1,Juiz Exemplo,000000000000
Gerado pelo site de apuração

O que fazer a cada novo evento

  1. Baixe os arquivos-modelo acima.
  2. Preencha com os dados reais do evento: carros inscritos, juízes de cada posto e horários de largada.
  3. Para o horário dos juízes, use a ferramenta Modelos do site de apuração — ela gera a versão pronta para uso a partir do horário real de cada posto. Não preencha essa coluna manualmente.
  4. Envie os arquivos preenchidos para quem cuida da parte técnica do site, para que sejam publicados a tempo do evento.
