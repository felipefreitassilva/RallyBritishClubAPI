Modelos de dados do Rally

Este repositório é a fonte de dados usada pelo aplicativo dos juízes e pelo site de apuração de resultados do Rally British Club. Cada edição do rally tem seu próprio branch (Rally67, Rally68, Rally69, ...) com os dados reais daquele evento. O branch develop, mostrado aqui, mantém apenas os arquivos-modelo abaixo — o ponto de partida que a organização de cada ano deve preencher com os dados do seu evento.

Como preparar um novo evento

  1. Crie um branch a partir de develop com o nome do evento, por exemplo Rally69.
  2. Substitua o conteúdo dos arquivos acima pelos dados reais do evento (carros, juízes, horários).
  3. Aponte o app e o site de apuração para esse branch (constante de versão em cada projeto).
  4. Ao final do evento, sincronize o branch do evento de volta com develop apenas se os modelos em si mudaram — os dados reais do evento permanecem no branch do evento, não em develop.

A cifra usada em Tempo Posto é uma simples troca de caracteres (ver cipherDates.py e config/ciphers.ts no app dos juízes) — não edite essa coluna manualmente.
